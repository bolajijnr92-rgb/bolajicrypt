BolajiCrypt

Encrypt, hash and generate keys. Everything runs on your device, nothing is uploaded.

AES-256-GCM with a key made from your password (PBKDF2, 600,000 rounds, random salt). A wrong password or edited data is always rejected.

A hash is one way: it cannot be decrypted. Use it to check that a file has not changed. SHA-1 is kept only for comparing old checksums.

Values come from the browser’s secure random generator.
